Ferrum Playground

Send events, break the receiver, crash the worker, and watch the delivery logic react.

What this is: a model of Ferrum's delivery pipeline running in your browser, using the worker's real rules (5 attempts, 5 s × 2n-1 backoff with ±20% jitter, 60 s lease, 90 s reclaim, signatures computed with real HMAC-SHA256). It is not the real service: no server or database is involved. To run the real thing, fork the sandbox. Time here is simulated, so use the speed control to skip waiting.
